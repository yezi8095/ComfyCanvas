# 亿幕画布 v0.2.0

## 主要更新

- 文本、图片、视频平台配置独立保存，可在对应节点切换已保存的平台和模型。
- 完善在线图片、视频生成参数、模型能力校验、状态提示和生成记录。
- 强化图片到视频等节点连接，保留生成前参数并支持修改或重新生成。
- 图片、视频和音频进入应用专属素材目录，按项目持久化；设置页可查看并打开真实存储位置。
- 新增可调整的画布自动保存间隔，改进项目切换、关闭和异步生成回流安全。
- 优化画布拖动、输入、节点菜单和大项目交互性能。
- 调整创作工作台、素材库、粗剪预览、配置面板及小窗口布局。
- 素材库支持双击全屏预览，画布支持从外部拖入图片、视频和工作流。

## 下载说明

- `亿幕画布_0.2.0_x64-setup.exe`：Windows x64 安装包，已包含 FFmpeg。
- `亿幕画布_0.2.0_便携版.zip`：解压后直接运行 `亿幕画布.exe`，请保留同目录的 `ffmpeg.exe`。

## 验证状态

- TypeScript/Vite 生产构建通过。
- Rust 锁定依赖检查通过。
- 25 个测试文件、201 项自动化测试通过。
